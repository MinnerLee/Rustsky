# Rustsky 学习笔记 24 · 小程序本地联调

课程顾客端使用微信小程序。这里用课程前端的本地预览副本保留点餐、购物车、地址、下单和订单记录页面，接口统一指向本机 Nginx 的 `http://127.0.0.1:8888`。[课程小程序前端](https://github.com/shuhongfan/sky-take-out/tree/267313f948bba2001fbc497995a39ef61f2c621f/mp-weixin)

## 打开本地项目

1. 确保 [管理端](http://127.0.0.1:8888/sky/) 可以访问，登录后把店铺设置为营业。
2. 在微信开发者工具里导入目录 `D:\rust\Rustsky\.preview\miniprogram`。项目配置使用本地测试 App ID 和本地请求设置。
3. 选购菜品，添加地址并下单。付款页会调用 `PUT /user/order/payment`，本地测试用户付款成功时响应带有 `simulated: true`。页面随后显示模拟付款成功。
4. 回到管理端，在待接单列表找到这笔订单，依次接单、派送、完成。顾客可在历史订单里选「再来一单」。

预览副本使用本机随机生成的开发凭证，并保存在 Git 忽略的 `.preview/` 下。正式小程序登录、商户配置、回调和付款状态查询见 [第 25 篇](25-wechat-payment.md)。

## 再来一单为什么要重新查价格

历史订单保存购买当时的价格，购物车要反映当前价格。点「再来一单」时，服务器先用 JWT 检查订单属于当前用户，再按历史明细的份数把商品加入购物车，重新查在售状态和现价。如果其中有一项已经停售，事务整体回滚，购物车保留之前的内容。

## 重新准备预览目录

课程前端原始文件在本机 `.preview/course-miniprogram/mp-weixin`。启动本地服务生成开发凭证后，可以重新生成预览副本：

```powershell
node D:\rust\Rustsky\tools\configure-miniprogram.cjs
```

脚本会设置本地接口地址，将本地上传图片的路径补成完整地址，并连接开发登录和模拟支付结果。可以先用 [Swagger](http://127.0.0.1:8888/docs/) 验证各个用户端请求，再在微信开发者工具里验证页面跳转。
