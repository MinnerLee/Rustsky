# Rustsky 学习笔记 17 · 套餐和菜品的关联

用管理员进入 [套餐管理](http://127.0.0.1:8888/sky/#/setmeal)。先启用一个套餐分类和至少一个菜品，再新建套餐并选择菜品份数。

套餐有自己的名字、分类、图片、价格和销售状态，存在 `setmeal`。套餐里的每种菜品和份数存在 `setmeal_dish`。例如套餐里有两份牛肉，关联表存一行牛肉和 `copies=2`。同一道牛肉还可以出现在其他套餐里，这就是多对多关系。

**事务把套餐和关联记录一起保存。** Rust 先核对选中的菜品是否仍在售，再从 `dish` 读取菜名和单价。写入套餐主表和关联表都成功时才提交。套餐售价独立设置，关联表里的单价来自数据库查询。

**两种销售状态需要保持一致。** 新套餐默认停售，全部菜品都在售时才可以起售。菜品停售时，Rust 在同一事务中将引用它的在售套餐一起停售。一个套餐只要仍引用该菜品，就会阻止删除该菜品。

本地服务启动并应用 [套餐授权脚本](../db/004-setmeal-grants.sql) 后，可重复运行以下检查。它会创建临时菜品和套餐，验证回显、编辑、起售、自动停售和删除保护，并清理临时记录。

```powershell
& D:\rust\Rustsky\tools\test-dish.ps1 -IncludeSetmeal
```

接口可在 [Swagger UI](http://127.0.0.1:8888/docs/) 的「套餐」分组查看。
