## 分页和表单

`pageSize` 是每页条数，`total` 是 MySQL 按当前筛选算出的总条数，所以分页控件能计算末页。改筛选或每页条数时回到第一页。员工列表还记录请求序号，避免慢的旧响应盖住最新搜索结果。

「保存并继续添加」清空表单并留在当前页面。「保存」成功后回到员工列表。修改页保留原工号，并且不提交初始密码字段。工号采用字符串，像 `RS-0007` 这样的前导零会保留。

## 操作练习

1. 新建一个虚构员工，记录工号，按姓名搜索。
2. 修改姓名和工号，再打开编辑页确认数据库回填的是新值。
3. 在列表禁用并重新启用账号。尝试用该员工登录，观察禁用和启用这两种结果。
4. 在 Network 中对照请求方法、URL 和请求体，再读 [员工与分类后端笔记](15-employee-status-edit-category.md)。
