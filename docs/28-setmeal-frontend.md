## 弹窗如何保住已选和份数

父组件 `addSetmeal.vue` 保存套餐表格，打开时复制一份已选菜品给子组件 `AddDish.vue`。子组件按 `dishId` 查找和合并选择，再用 `$emit('checkList', …)` 回传。取消时父组件直接关闭弹窗，确认时才替换表格。子组件会优先取已有记录的份数，所以换分类或重新搜索不会把 3 份改成 1 份。

金额保留为字符串直到提交，Rust 按小数校验并存进 MySQL 的 `DECIMAL`。明细只提交 `dishId` 和 `copies`。这样客户端无需传价格，数据库仍会保留套餐菜品的信息。

## 操作练习

1. 上架两道菜，给它们分别归类。在套餐表单里先按分类选一道，再按名称搜索另一道。
2. 上传 JPEG 或 PNG，并把两道菜分别设置成不同份数。保存后重新打开，核对比例和图片。
3. 在编辑弹窗里尝试改勾选再取消，核对表格仍显示原值。重新打开确认保留原份数。
4. 用套餐列表启售、停售再删除。选中两条记录批量删除，查看 Network 中的 `ids` 参数。后端对起售及引用场景的规则见 [套餐后端笔记](17-setmeal-management.md)。
