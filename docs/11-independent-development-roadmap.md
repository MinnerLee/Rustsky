# Rustsky 学习笔记 11 · 从跟做走到独立开发

用已经跑通的登录功能当练习场。先学会追踪一个请求，再自己完成一个小接口。Rustsky 的核心是 Rust 业务开发。Nginx 先学会转发和排查，MySQL 则要学到能自己写查询和维护业务数据。

## 第一关：能自己定位问题在哪一层

启动本地环境后，依次访问下面三个入口。它们回答的是不同的问题。

| 看哪里 | 能确认什么 |
| --- | --- |
| `http://127.0.0.1:8080/health` | 能直连第一个 Rust 实例 |
| `http://127.0.0.1:8888/health` | Nginx 能把健康检查转到某个 Rust 实例 |
| Swagger UI 的 `POST /api/employee/login` | 这次请求实际走了 Nginx、Rust 登录逻辑和 MySQL |

`/health` 只检查 HTTP 服务是否响应。它返回成功时，具体业务查询仍可能失败。先看浏览器 Network 面板的请求地址、HTTP 状态和响应，再决定查 Nginx 日志、Rust 日志还是 MySQL。页面能打开、接口返回 `502` 时，先看两个 Rust 实例是否响应。登录返回 HTTP `200` 且 `code: 0` 时，看业务错误原因。

**练习：** 在 `tools/nginx.conf` 里找到 `listen`、`location /api/`、`proxy_pass` 和 `upstream`，用自己的话解释 `:8888/api/employee/login` 最后为什么变成 `:8080/admin/employee/login`。再去浏览器里找到 `X-Rustsky-Upstream`，确认实际实例。能解释地址变化并区分上述故障，就可以继续写业务。负载均衡策略、缓存和性能调优等遇到需求时再学。

## 第二关：能在 MySQL 里先把数据查对

从 `employee` 表开始。先认识库、表、行、列和主键，再学这几项：

1. `SELECT` 选要返回的列，`WHERE` 筛选行。
2. `ORDER BY` 决定顺序，`LIMIT` 和 `OFFSET` 截取一页。
3. `COUNT(*)` 统计符合条件的总行数。分页一般需要返回当前页记录和总数。
4. 等做新增、编辑和禁用时，再练 `INSERT`、`UPDATE`、唯一约束和参数绑定。需要动多张表时，再学 `JOIN` 和事务。

**第一次练习只读。** 在 `rustsky_dev` 中查询启用员工，列出编号、用户名、姓名和状态，按编号降序取前五条。提示是 `WHERE status = 1`、`ORDER BY id DESC`、`LIMIT 5`。再用相同条件写一次 `COUNT(*)`。如果目前只有一个 `admin`，只返回一条属于正常结果。执行 SQL 的方式见 [MySQL 入门笔记](07-nginx-mysql-for-beginners.md)。

**验收：** 能解释 `WHERE` 和 `LIMIT` 的区别，能说明为什么列表和总数应使用同一套筛选条件，并确认响应需要的字段里没有密码哈希。想练修改时，用单独的练习表和虚构记录。

## 第三关：把一条 SQL 变成一个能联调的接口

建议以员工分页查询作为第一项独立任务。前端已有 `/employee/page` 的调用，在 Nginx 下浏览器请求的是 `/api/employee/page`。动手前，从前端调用处确认方法、查询参数和页面读取的返回字段，再补 Rust 接口。

| 你要做的事 | 做到什么算完成 |
| --- | --- |
| 写一小份接口约定 | 能明确前端发什么、成功返回哪些字段、未登录如何处理 |
| 在 MySQL 中验证查询 | 能查当前页、总数和没有匹配项的情况，排序稳定 |
| 在 Rust 里接起来 | SQLx 用参数绑定执行查询，Axum 校验页码、页大小和令牌 |
| 用 Swagger 和页面联调 | 有效令牌查到列表，无令牌返回 `401`，没有匹配项时得到空列表 |

可以用这个顺序排查：先在 MySQL 跑 SQL，再直连 Rust 测接口，再经 Nginx 测同一个接口，最后看 Vue 页面。每过一层再加下一层，出问题时就知道从哪找起。

## 第四关：把同样的方法用在新的业务上

能独立完成员工列表后，依次练新增员工、编辑与禁用，再把相同方法用到分类和菜品。做到套餐时练多表关系，做到下单时练事务。比如订单主记录和明细都写成功才提交，任何一步失败就一起回滚。

每次只拿一个小功能走完这五步：**看页面 → 定接口 → 写并验证 SQL → 写 Rust → 联调**。遇到卡点时，先用一条具体证据描述它，例如「直连 Rust 返回 `200`，经 Nginx 返回 `404`」。向别人问这种问题，得到的帮助也更容易变成你下次能复用的经验。
