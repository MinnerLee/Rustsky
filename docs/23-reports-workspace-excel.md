# Rustsky 学习笔记 23 · 营业统计、工作台和 Excel

## 先定统计口径

同一个数字在不同页面也要有一致的含义。Rustsky 以北京时间的自然日分组，日期按订单创建时间归属，数据库保存 UTC 时间。筛选 11 月 1 日至 3 日时，SQL 从 1 日零点开始，到 4 日零点之前结束。

| 指标 | 计算方式 |
| --- | --- |
| 全部订单数 | 日期范围内的全部订单 |
| 有效订单数 | 已完成且已支付的订单 |
| 营业额 | 有效订单的金额之和 |
| 完成率 | 有效订单数 ÷ 全部订单数 |
| 平均客单价 | 营业额 ÷ 有效订单数 |
| 新增用户 | 当日首次创建的用户记录数 |
| 累计用户 | 当日结束时已经创建的用户记录数 |
| 销量前十 | 从有效订单的明细中按商品汇总数量，按销量降序取前十 |

分母为 0 时，完成率和平均客单价返回 0。没有订单的一天也会补上 0，图表的日期和数值仍能一一对应。开发数据库里已完成的模拟支付订单也参与统计，便于本地观察各指标。

## MySQL 查询和前端图表怎么分工

MySQL 用 `GROUP BY` 将同一日期的订单归在一起，再用 `COUNT` 和 `SUM` 得到订单数和营业额。Rust 把结果补齐并按日期排序。统计页从 `/api/report/` 获取日期和数值，工作台从 `/api/workspace/` 获取今日数据和菜品、套餐状态。

如果当天有两笔订单，一笔 59.50 元已完成，一笔 29.75 元已取消，营业额就是 59.50 元，有效订单数是 1，订单完成率是 50%。这也是区分统计口径最直接的练习。

## Excel 文件如何生成

管理端调用 `GET /api/report/export`，默认导出最近 30 个完整自然日。也可提供 `begin` 和 `end`。Rust 用同样的每日统计生成工作表，金额和完成率作为数值写入 Excel，方便排序、求和和设置格式。生成工作交给 Tokio 的阻塞线程池，接口返回带有 `Content-Type` 和 `Content-Disposition` 的文件响应。[rust_xlsxwriter 文档](https://rustxlsxwriter.github.io/)

在管理端「数据统计」选择日期范围，观察营业额、订单和用户图表。「数据导出」下载最近 30 天的 Excel。也可在 [Swagger](http://127.0.0.1:8888/docs/) 查看查询和导出接口。

```powershell
& D:\rust\Rustsky\tools\test-dish.ps1 -IncludeSetmeal -IncludeCache -IncludeReports
```

脚本完成一笔 59.50 元的测试订单，检查统计增加的金额，再打开下载的工作簿，验证营业额单元格与接口返回一致。测试结束后会清理这笔订单。
